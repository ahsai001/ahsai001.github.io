⚠️ Terdeteksi kamu membuka file ini langsung via file://

Browser memblokir permintaan jaringan cross-origin dari file:// sehingga semua pengecekan akan selalu gagal.

Solusi:
  • Buka via GitHub Pages jika sudah deploy.
  • Atau jalankan local server: python3 -m http.server 8080 lalu buka http://localhost:8080/tools/connection-checker.html
  • Atau install npx serve . di root folder proyek.

Klik tombol di bawah untuk tetap mencoba (mungkin gagal).
